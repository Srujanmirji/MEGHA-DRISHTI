# Models

Do not commit large checkpoints directly to this repository.

The MVP uses deterministic interpolation as a baseline. The proposed generative research path is NVIDIA PhysicsNeMo CorrDiff, trained/adapted on authorized paired coarse/high-resolution meteorological data.

Model cards should record:
- training data,
- train/validation/test periods,
- variables,
- spatial domain,
- lead-time conditioning,
- normalization,
- checkpoint hash,
- metrics,
- known failure modes.
